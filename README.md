# 龙旗之外 · Vercel 共享编辑版

这是“像素工坊”的可部署版本。访客可在 32 × 32 画布中编辑沈月玲或林巳，并点击“替换网页角色（共享）”。最后一次发布会成为所有访客重新打开页面时看到的版本。

页面聚焦两位角色的 32 × 32 像素稿，并提供原图、10 倍最近邻预览、色板 CSV 和验证 JSON。

## 部署到 Vercel

1. 将本目录作为 Vercel 项目根目录导入或部署。
2. 在 Vercel 项目的 **Storage** 页面创建一个 **Private Blob** 存储，并连接到本项目。Vercel 会自动添加 `BLOB_READ_WRITE_TOKEN`。
3. 重新部署一次项目。

项目已经固定使用 Node.js 24、`dist` 静态输出目录和 `/api/sprite` 共享保存接口，不需要填写额外构建命令。

## 访问规则

- 不设账号和密码；任何能够打开网页的人都能查看、编辑和替换共享角色。
- 后发布的版本覆盖先发布的版本。
- 发布前，浏览器和服务端都会验证：32 × 32、最多 16 种任意 RGB 颜色、Alpha 只能为 0 或 255。
- 如果 Blob 尚未连接或网络不可用，编辑器会明确提示“仅保存到当前浏览器”，不会假装共享发布成功。
- “恢复原稿”只把当前编辑画布恢复为项目原稿；需要再点击共享替换按钮，才会把原稿发布给所有人。

## 本地查看

直接用静态服务器打开 `dist` 可以测试绘图、导入、导出和浏览器本地保存。共享发布需要 Vercel Functions 与 Blob，因此只有部署后才会生效。
